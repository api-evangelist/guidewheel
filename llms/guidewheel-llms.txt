# Guidewheel

> Guidewheel is the first FactoryOps platform. It uses non-invasive, clip-on current sensors that attach to any machine's power leads — regardless of age, make, or model — and stream a real-time "heartbeat" of machine state (running, idle, down) over cellular, with no PLC access or plant Wi-Fi required. The platform turns that signal into real-time OEE, downtime categorization, Pareto analysis, cycle-time tracking, and production reporting so manufacturers can reduce downtime, increase production from existing assets, and continuously improve. Trusted by hundreds of leading manufacturers including Georgia-Pacific, Hershey, Ecolab, US Steel, GM, and Johnson & Johnson.

## Key facts
- Category: FactoryOps / machine monitoring / OEE software for manufacturing
- Founded by: Lauren Dunford (CEO) and Weston McBride (CTO)
- Core differentiator: non-invasive clip-on current sensors that work on any machine without PLC/SCADA integration; deploys in days, not months
- Connectivity: cellular — no reliance on plant Wi-Fi
- Integrations: SAP (native), Oracle, Epicor, Microsoft Dynamics, Salesforce, Power BI, MaintainX, and more via Workato and an open API
- Performance dataset: 3,000+ machines and 74M+ machine-minutes analyzed
